Generated CMS contract manifest for USX.

This package has no authored source of its own: `src/contracts.js` is generated by `pnpm generate:contracts` (run from the repo root) from every component's `config.json` in `packages/usx-react/src/components/`. `pnpm build` (or this package's own `build` script) regenerates it and compiles `dist/component-contracts.json` for non-JS consumers (e.g. the SOLEX CMS).

## Structure

- `src/contracts.js`: generated CMS contract manifest, keyed by component name — do not edit by hand
- `dist/component-contracts.json`: build output (plain JSON compile of `src/contracts.js`), gitignored

`pnpm validate:configs` (part of `pnpm test`) checks that `src/contracts.js` is current with every component's `config.json`.

See [solex-cms-overview.md](../../local-docs/solex-cms-overview.md) for the contract shape and how the CMS consumes it.
