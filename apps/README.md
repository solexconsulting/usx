Runnable applications in this monorepo. Shared, publishable code lives in
[`packages/`](../packages) instead — these apps mostly consume it.

## [storybook](./storybook)

The Storybook host that documents USX components, rendering each one as
React, Django, and static HTML variants. See
[storybook/README.md](./storybook/README.md).

## [storybook-django](./storybook-django)

A small Django app that server-renders components for the Django-flavored
stories in `storybook`. See
[storybook-django/README.md](./storybook-django/README.md).

## docs (planned)

A documentation site for the design system — guides, API references,
contribution docs, and design guidelines for designers and engineers. Not yet
built.
